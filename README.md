# BOX — Prompt Library & Web Resource Vault

A fast, modern prompt library and AI website link hub with full CRUD, variable playgrounds, category management, and MongoDB + Clerk integration.

## 🚀 Features

- **Prompt Management**: Organize, tag, favorite, and customize AI prompt templates with live variable interpolation.
- **Categorization**: Customizable categories with custom colors and icons.
- **Resource Hub**: Quick links to your favorite AI tools and websites.
- **Secure Authentication**: Clerk user management and authentication.
- **Persistence**: Hybrid storage support (MongoDB Atlas & LocalStorage fallback).
